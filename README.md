## 项目简介 🎯
miniBili 是一个在线视频分享系统，独立完成后端，双端一体：
- **用户端**：注册登录、分片投稿、播放、弹幕、点赞、评论、投币、个人数据中心、视频专栏管理，Elasticsearch 加持智能搜索。
- **审核端**：一站式完成视频审发、用户系统设置与视频分类管理。

未来计划拆分为微服务：Nacos 注册中心 + Gateway 统一网关 + OpenFeign 服务调用 + Seata 分布式事务，**火箭发射就绪** 🚀。

---

## 账号模块 👤
- **登录**：账号密码安全登录，无缝访问。
- **注册**：填写必要信息，3 秒完成，欢迎加入社区！

---

## 主站模块 📼
- **视频列表**：多分类快速找片，不迷路。
- **视频详情**：流畅播放 + 实时评论/点赞/收藏/弹幕/投币，**三连**安排！
- **推荐视频**：Elasticsearch 分词匹配，**相关视频**自动送到嘴边。

---

## 创作中心模块 ✍️
- **发布视频**：分片上传 → RocketMQ 异步合并 → 转码 → TS 切片，**稳如老狗**。
- **数据统计**：粉丝、播放、评论、弹幕、点赞、收藏、投币**总量 + 近 7 天曲线**，一图胜千言。
- **互动管理**：评论/弹幕**一键净化**，社区氛围由我守护。

---

## 个人中心模块 👑
- **个人信息**：关注、粉丝、获赞、播放数，**影响力**一目了然。
- **投稿管理**：编辑、删除、再投，**我的视频我做主**。
- **粉丝管理**：粉丝列表随时看，**双向奔赴**不迷路。

## 搜索模块 🔍
- **视频搜索**：Elasticsearch + IK 分词，**秒回结果**。
- **搜索热词**：Redis 实时统计，**大家都在搜**的才是潮流。

- **分类管理**：增删改查，**类目清爽**。
