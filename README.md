# miniBili
## 项目简介
该项目是一个在线视频分享系统，独立完成后端，双端一体：用户端支持注册登录、分片投稿、播放、弹幕、点赞、评论、投币、个人数据中心及视频专栏管理，使用elesticserch实现视频搜索功能；审核端一站式完成视频审发、用户系统设置与视频分类管理。目前正在进一步完善管理端后端，后期会拆分为微服务项目，微服务计划：项目采用nacos实现服务注册与发现，统一配置管理，通过gateway网关统一对外提供服务，实现负载均衡，服务与服务之间采用openfeign进行相互调用，使用seata解决分布式事务。
### 账号模块
- 登录：用户可以通过账号和密码安全登录系统，体验无缝的访问过程。
- 注册：新用户可以轻松注册账号，填写必要信息后即可快速完成注册，加入我们的社区。
### 主站模块
- 视频列表展示：精心设计的视频列表展示功能，让用户可以根据不同分类快速找到感兴趣的内容。
- 视频详情：提供详尽的视频信息，包括流畅的视频播放、实时评论、点赞、收藏、弹幕、投币等互动功能，增强用户参与感。
- 推荐视频：基于当前视频标题，通过Elasticsearch分词技术，智能推荐相似视频，让用户发现更多精彩内容。
### 创作中心模块
- 发布视频：用户可以分片上传视频，系统使用redis消息队列进行异步处理，包括视频合并、转码和切割TS分片，确保上传过程快速稳定。
- 数据统计：通过直观的图表展示用户粉丝、播放量、评论、弹幕、点赞、收藏、投币的总数及近一周数据曲线图，帮助创作者洞察内容表现。
- 互动管理：强大的评论管理和弹幕管理功能，让创作者轻松维护社区环境，提升用户体验。
### 个人中心模块
- 个人信息展示：全面展示用户的关注数、粉丝数、获赞数、播放数等个人信息，让用户随时掌握自己的社区影响力。
- 投稿视频管理：用户可以方便地管理自己上传的所有视频，包括编辑、删除等操作，灵活掌控内容发布。
- 粉丝管理：用户可以查看和管理自己的粉丝列表，与粉丝建立更紧密的联系，增强社区互动。
### 搜索模块
- 视频搜索：利用强大的Elasticsearch搜索引擎，结合精准的IK分词器，快速检索视频关键信息，帮助用户找到所需内容。
- 搜索热词：通过Redis的incrementScore功能实时记录热词搜索次数，为用户提供热门搜索建议，提升搜索体验。
### 管理后台模块
- 分类管理：管理员可以灵活新增、修改、删除视频分类，确保内容分类清晰有序，提升用户浏览体验。
- 视频管理：管理员对用户上传的视频进行严格审核，保证内容符合规定和标准，同时对优质视频进行推荐、删除等操作，维护社区内容质量。
- 用户管理：管理员可以查看用户列表、管理用户状态，确保社区秩序和用户安全。
- 系统设置：管理员可以设置用户文件上传大小、分级数量、评论限制、弹幕限制等系统参数，灵活调整系统配置，优化用户体验。
